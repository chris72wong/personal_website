# Personal website

My portfolio, built with HTML, CSS, and JavaScript.

[christopherwong.me](https://christopherwong.me)

To preview locally, run `python -m http.server 4173` and open [localhost:4173](http://localhost:4173).

Tests: `node --test --test-isolation=none tests/projects.test.cjs`.
Browser checks: `node tests/transit.browser.cjs` and `node tests/viewport.browser.cjs` (Playwright and Edge).
