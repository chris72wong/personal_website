# Personal website

Static HTML, CSS, and JavaScript. Serve the repository with a local HTTP server to preview it.

Desktop sections fill the available screen height below the sticky navigation. Each panorama scales to fit both the width and height while keeping its original aspect ratio, with space around the artwork when the screen proportions differ. All section arrows remain visible when navigating to a section. Text and controls scale with the artwork width. Touch devices retain a 1280px panoramic canvas, initially scaled down to show the full page width, with unrestricted pinch zoom. Projects stay side by side, all four education/experience milestones remain over the forest, and no mobile camera panning or automatic label scrolling occurs.

The welcome yacht gently moves right at about 3.2 scene pixels per second while bobbing. It starts about one and a half boat lengths from the left on first load, fully exits on the right, and loops back in from offscreen left. Projects has a small painted plane flying from right to left with a gentle climb: an 18-second crossing and a 10-second gap. The moonlit alpine railway retains its three-car train at the original speed, with each carriage following both wheel contacts on the track and milestones lighting as it passes. A static stone parapet follows the bridge curve in front of the train, hiding the wheels while keeping the carriage bodies visible. The name types when it enters view, followed by a blinking white square cursor. These animations pause offscreen, in hidden tabs, during project popups, and for reduced motion. Reduced motion hides the flying plane. Clouds, water, stars, and lights are painted into the backdrops; filtered duplicate scenery, resort yachts, section entrance effects have been removed. Active and hovered navigation links have a soft white glow.

Projects uses a subdued painted sunset resort panorama, matching the alpine scene's broader shapes and restrained highlights. Names, descriptions, and translucent View project buttons sit beneath the three buildings in square glass cards with glowing gold outlines. Project dialogs share the glass styling and square controls. Both scene titles appear without decorative rules, and Projects has no subtitle. The buttons open the corresponding project dialogs and support keyboard activation. Without JavaScript or native dialog support, visible fragment links lead to the complete articles instead. The optimized backdrop is `images/projects-resort-subtle.webp`; its generation prompt is recorded in `images/resort-subtle-artwork.md`. The transparent plane is `images/resort-plane.webp`, with its prompt recorded in `images/resort-plane-artwork.md`. Previous artwork remains available for reference.

White double chevrons link from Home to Projects, Projects to Education/Experience, and the final scene back to Home. The final section meets the full-width copyright divider directly.

Project popups keep their desktop presentation, keyboard containment, focus restoration, scroll restoration, and Back/Forward behavior. Explicit open/close transitions remain. Complete project articles remain available without JavaScript or dialog support. No cookies or browser storage are required. Restricted history, older Safari media listeners, and suspended closing animations are supported.

## Checks

- `node --test --test-isolation=none tests/projects.test.cjs`
- `node tests/viewport.browser.cjs` with Playwright and Microsoft Edge available checks complete proportional scenes and visible, clickable arrows at nine desktop viewport sizes, including ultrawide monitors and short browser windows.
- `node tests/transit.browser.cjs` with Playwright available and Microsoft Edge installed. WebKit runs when installed; set `SITE_BROWSER=edge` or `SITE_BROWSER=webkit` to select an engine. The browser checks default to `http://127.0.0.1:4173`; set `SITE_URL` for another local preview. Screenshots default to `personal-website-review` in the system temporary directory; override with `TRANSIT_SCREENSHOT_DIR`.

Browser coverage includes desktop viewport fitting and resizing, matching artwork proportions at 320–900px phone viewports, initial overview scaling, unrestricted zoom metadata, actual project buttons, keyboard activation and focus restoration, touch project dialogs, the plane's direction/climb/loop gap and motion pausing, live boat motion, a full train loop with all six bogies aligned, reduced motion, arrow navigation, footer alignment, and usable no-JavaScript article links. Device emulation complements testing on a physical phone.
