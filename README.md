# Personal website

Static HTML, CSS, and JavaScript. Serve the repository with a local HTTP server to preview it.

Desktop sections fill the available screen height below the sticky navigation. Each SVG panorama fills the full width through proportional cover scaling, cropping excess artwork instead of leaving side gaps. Vehicles, tracks, and foreground details scale together inside the same SVG. The welcome scene crops from the top to keep the yacht visible. All section arrows remain visible when navigating to a section. Text and controls scale with the scene width, and milestones sit above the final arrow even in short windows. Touch devices retain a 1280px panoramic canvas, initially scaled down to show the full page width, with unrestricted pinch zoom. Projects stay side by side, all four education/experience milestones remain over the forest, and no mobile camera panning or automatic label scrolling occurs.

The welcome yacht moves right at about 6.3 scene pixels per second while bobbing. It starts about one and a half boat lengths from the left on first load, fully exits on the right, and loops back in from offscreen left. Projects has a small painted plane flying from right to left with a gentle climb: a 22-second crossing and a 1-second gap, repeating every 23 seconds (slightly less often than the train). Flight endpoints follow the visible SVG crop, keeping the plane in the sky and limiting its offscreen time to under two seconds. The moonlit alpine railway retains its three-car train at the original speed, with each carriage following both wheel contacts on the track and milestones lighting as it passes. A static stone parapet follows the bridge curve in front of the train, hiding the wheels while keeping the carriage bodies visible. The name types when it enters view, followed by a blinking white square cursor. These animations pause offscreen, in hidden tabs, during project popups, and for reduced motion. Reduced motion hides the flying plane. Clouds, water, stars, and lights are painted into the backdrops; filtered duplicate scenery, resort yachts, section entrance effects have been removed. Navigation uses neutral frosted glass with a faint white tint, with a soft white glow on active and hovered links. Roboto Mono is used consistently for all website text and controls.

Projects uses a subdued painted sunset resort panorama, matching the alpine scene's broader shapes and restrained highlights. Names, short functional descriptions, and translucent Learn more buttons sit beneath the three buildings in square blue glass cards with glowing ice-blue outlines. All project dialogs share the Travel Dashboard ice-blue accent, glass styling, and square controls. Cards use a plain glowing outline without corner ornaments. Inside dialogs, text has no surrounding frame or shadow, and only the project screenshot has a thin accent border and soft glow. Both scene titles use the original compact 28–32px heading size without decorative rules, and Projects has no subtitle. The buttons open the corresponding project dialogs and support keyboard activation. Without JavaScript or native dialog support, visible fragment links lead to the complete articles instead. The optimized backdrop is `images/projects-resort-subtle.webp`; its generation prompt is recorded in `images/resort-subtle-artwork.md`. The transparent plane is `images/resort-plane.webp`, with its prompt recorded in `images/resort-plane-artwork.md`. Previous artwork remains available for reference.

Education/Experience uses scalable gold emblems traced from the supplied reference for Wind Group, Brock University, and RBC, linked by a continuous thin gold timeline. The emblems sit in square translucent frames with a soft gold glow; passing train highlights use the same gold accent and give all text beneath the active icon the same subtle glow as the scene titles. Milestone text retains Roboto Mono and its existing size hierarchy; dates share the pale blue Projects text colour. Project dialog View project and Close controls use matching gold text, borders, glows, and focus outlines against the blue cards. The blinking name cursor shares the title's subtle glow.

White double chevrons link from Home to Projects, Projects to Education/Experience, and the final scene back to Home. Copyright sits at the bottom left of the final scene, with no separate footer strip, divider, or trailing page gap.

Project popups keep their desktop presentation, keyboard containment, focus restoration, scroll restoration, and Back/Forward behavior. Explicit open/close transitions remain. Complete project articles remain available without JavaScript or dialog support. No cookies or browser storage are required. Restricted history, older Safari media listeners, and suspended closing animations are supported.

On desktop, the Projects SVG crops excess sky to expose the gym, house, and airport above their cards. Framing follows the window dimensions and card height; short desktop windows use more compact cards, with space above the final arrow. Cover scaling remains proportional and fills the frame. The plane route follows the reframed viewport. Touch devices keep the original Projects viewBox and card placement.

## Checks

- `node --test --test-isolation=none tests/projects.test.cjs`
- `node tests/viewport.browser.cjs` with Playwright and Microsoft Edge available checks full-width proportionally cropped scenes and visible, clickable arrows at nine desktop viewport sizes, including ultrawide monitors and short browser windows.
- `node tests/transit.browser.cjs` with Playwright available and Microsoft Edge installed. WebKit runs when installed; set `SITE_BROWSER=edge` or `SITE_BROWSER=webkit` to select an engine. The browser checks default to `http://127.0.0.1:4173`; set `SITE_URL` for another local preview. Screenshots default to `personal-website-review` in the system temporary directory; override with `TRANSIT_SCREENSHOT_DIR`.

Browser coverage includes desktop viewport fitting and resizing, original artwork proportions at 320–900px phone viewports, initial overview scaling, unrestricted zoom metadata, actual project buttons, keyboard activation and focus restoration, touch project dialogs, the plane's direction/climb/loop gap and motion pausing, live boat motion, a full train loop with all six bogies aligned, reduced motion, arrow navigation, copyright placement inside the final scene, and usable no-JavaScript article links. Device emulation complements testing on a physical phone.
